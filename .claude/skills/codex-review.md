# codex-review スキル

コードの変更を Codex にレビューさせ、同意した指摘を適用する。

## 実行手順

### 1. レビュー実行

未コミットの変更全体をレビュー対象とする場合:

```bash
codex review --uncommitted
```

特定のブランチとの差分をレビュー対象とする場合:

```bash
codex review --base <branch>
```

特定のコミットをレビュー対象とする場合:

```bash
codex review --commit <sha>
```

### 2. レビュー結果の提示

レビュー結果を整理してユーザーに提示する。各指摘について:
- 問題の内容と該当箇所
- 修正の提案
- 対応するかどうかの確認

### 3. 修正の適用

ユーザーが同意した指摘に対して `codex apply` で差分を適用する:

```bash
codex apply
```

`codex apply` は Codex が直前に生成した diff を `git apply` で適用する。
適用後は変更内容を確認し、意図通りであることを検証する。

## 注意事項

- レビュー結果はすべてユーザーに提示し、適用前に必ず確認を取る
- ユーザーが同意しない指摘は適用しない
- 適用後にテストや動作確認を促す
